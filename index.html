5. Procédure self-host

  1. Sur le PC : python -m http.server 8000
  2. Relève l'IP LAN du PC et mets la PS4 sur le même réseau.
  3. Navigateur PS4 → http://IP_DU_PC:8000/index.html
  4. Lance le diagnostic, note les échecs.
  5. Paramètres → Système → désactive les MAJ automatiques.
  6. Ouvre une chaîne et mets-la en favori pour la garder hors ligne.
